# Homepage and audience entry — 2026-09-15

## Result

The application now opens on a bilingual homepage with player and developer entry cards. It reuses the dark gaming palette and locally bundled Hades / Outer Wilds artwork. Mobile places the entry cards before the decorative artwork. The `ui-ux-pro-max` design-system search informed feature hierarchy and game-focused imagery; existing colors and system fonts were retained without introducing its optional 3D effects or animation dependencies.

Player discovery emphasizes price, recommendations, and saved games. Developer research has a distinct introduction, cyan actions, research results with review counts, sort controls, and an explicit estimated-ownership/revenue panel. Both retain game and collection intelligence with source disclosure. Collection revenue is displayed only in the developer perspective.

There is no direct player/developer toggle inside a workspace. Native hash links provide entry, Home, refreshable workspace addresses, and browser history. The homepage makes no workspace data/insight calls. Query interpretation cannot change the chosen page or authenticated account role. Returning home ends the current search and draft session, while saved collections and the language preference remain stored.
