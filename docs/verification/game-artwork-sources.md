`GameArtwork` matches normalized exact sample titles, never numeric database IDs or partial titles. Unknown games and failed image loads show a decorative gamepad fallback while the surrounding card retains the game title. The selected image can load eagerly; list images load lazily. No AI or catalog service contract changes are required.
